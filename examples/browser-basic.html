🌊 Flo Browser SDK Example

Real-time streams and KV access from the browser

To run this demo:
1. Start the Flo server: cd zflo && zig build run -- --port 9000
2. Serve this file: cd sdks/js && python3 -m http.server 8080
3. Open http://localhost:8080/examples/browser-basic.html

Note: The @floruntime/web package is optimized for real-time browser applications:
  • Streams: Subscribe to and publish real-time events (pub/sub)
  • KV (read-only): Access configuration, feature flags, user preferences
